A Python program that writes the funniest single line of wedding vows a robot couple could say: one deterministic line, at most 160 characters, to `/output/entry.txt`. The vow is a real promise — to cherish a partner through every patch, power cut, and low-battery warning — with the laugh landing in the last few words, when the tenderest wedding gesture turns literal.

## Run it

```sh
python3 main.py
```

That writes the vow to `/output/entry.txt` (creating `/output` if needed). The output is byte-identical on every run: a single line of 135 characters, no trailing newline, standard library only.
